Informativa sulla privacy

Ultimo aggiornamento: 5 settembre 2026

SideSchedule è un’app per macOS sviluppata da Ingo Jurz, Graz, Austria. Questa pagina spiega quali dati l’app tocca, cosa lascia il tuo Mac e cosa non lo lascia mai.

In breve

  • Eventi e note restano sul tuo Mac. Non vengono mai caricati da nessuna parte.
  • L’app non ha analisi, tracciamento, SDK per i crash report né pubblicità.
  • Le uniche chiamate di rete dell’app: verifica della licenza (Lemon Squeezy) e controllo degli aggiornamenti (Sparkle, via GitHub).
  • Questo sito carica uno script di terze parti per i link di affiliazione — vedi «Questo sito» più sotto.

Questo sito

L’app in sé non ti traccia. Questo sito carica esattamente uno script di terze parti: lo script di affiliazione di Lemon Squeezy (lmsqueezy.com/affiliate.js). Se arrivi tramite il link di un partner (un URL con ?aff=…), lo script comunica a Lemon Squeezy quale partner ti ha inviato, così riceve la sua commissione se in seguito acquisti una licenza. Salva un identificativo anonimo: niente nome, niente email, nessun profilo di navigazione. Se arrivi senza un link di questo tipo, lo script non fa nulla.

Lo script viene caricato dai server di Lemon Squeezy; per quella richiesta vale la loro informativa sulla privacy. L’app non lo carica mai.

Dati del calendario

SideSchedule legge i tuoi calendari tramite il framework EventKit di Apple per mostrare la tua giornata. Se crei, rinomini, sposti o elimini eventi, le modifiche vengono riscritte in Apple Calendar. Le note che scrivi in SideSchedule restano in locale sul tuo Mac (e opzionalmente duplicate come file Markdown in una cartella a tua scelta, o nella descrizione dell’evento in Apple Calendar se attivi quell’opzione). Nulla di tutto questo viene trasmesso a noi o a terzi.

Accesso ad Accessibilità

Se attivi «Mantieni le finestre fuori dalla barra», SideSchedule usa l’API di Accessibilità di macOS per osservare e riposizionare le finestre dell’app in primo piano, così non scivolano sotto la barra laterale. Tutto avviene sul tuo Mac. Nessun titolo di finestra, nome di app o dato d’uso viene raccolto o trasmesso.

Attivazione e verifica della licenza

Quando inserisci una chiave di licenza, SideSchedule contatta l’API di Lemon Squeezy (api.lemonsqueezy.com) via HTTPS per attivarla e verificarla periodicamente. La richiesta include la chiave e il nome host del tuo Mac (usato come etichetta di attivazione per riconoscere il dispositivo nel tuo portale clienti Lemon Squeezy). La chiave è salvata nel Portachiavi di macOS, non in preferenze in chiaro.

Aggiornamenti

SideSchedule controlla gli aggiornamenti tramite il framework Sparkle, che scarica un file appcast ospitato su GitHub (github.com). GitHub può registrare il tuo indirizzo IP nel servire quel file, secondo la propria informativa sulla privacy. I download degli aggiornamenti sono firmati e verificati con una firma EdDSA prima dell’installazione.

Report di diagnostica

Puoi inviare manualmente un report di diagnostica via email dalla barra dei menu o dalle Impostazioni. Sempre su tua iniziativa: l’app raccoglie log recenti, crash report e informazioni di base sul sistema in una bozza che puoi rivedere, modificare o eliminare prima dell’invio. Questi file possono contenere percorsi locali e il nome host del tuo Mac. Nulla viene mai inviato automaticamente.

Cosa non raccogliamo mai

  • Nessun account né registrazione
  • Nessuna analisi né statistica d’uso
  • Nessun identificativo pubblicitario
  • Nessun dato di crash, a meno che tu non lo invii via email
  • Nessun contenuto di calendario, nota o informazione sulle finestre
